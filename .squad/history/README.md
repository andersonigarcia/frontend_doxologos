## 🔄 Regra de Governança do Squad
A cada conclusão de esteira (*Fast-Track*, *Standard-Track* ou *Full-Track*), o **Orquestrador Central** deve garantir que:
1. Novas decisões de arquitetura e produto sejam registradas com uma nova ADR nesta pasta (`.squad/history/`).
2. O arquivo vivo [`03_SQUAD_MEMORY.md`](file:///c:/Users/ander/source/repos/frontend_doxologos/.squad/03_SQUAD_MEMORY.md) seja alimentado com o resumo da decisão para alimentar o contexto dos próximos ciclos.
